# Merchant OS

Operations platform for cash-on-delivery e-commerce in Morocco: orders and confirmation calls, stock, Sendit shipping, online store connections, returns, cash and profit, owner pay.

The application lives in [`merchant-os/`](merchant-os/README.md). Start there.

The Maison Shaimaa storefront that used to be at the root of this repository was removed on 2026-11-18 (an abandoned experiment); it remains in the Git history.
